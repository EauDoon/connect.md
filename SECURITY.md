# Security

The security policy for this repository is [.github/SECURITY.md](.github/SECURITY.md),
the copy GitHub shows on the Security tab. It covers how to report a
vulnerability privately, the fallback when private reporting is unavailable,
safe research boundaries, and disclosure.

Do not file a public issue, pull request, or discussion with vulnerability
details. connect.md is pre-launch and has no service-level commitment for
response times yet.
