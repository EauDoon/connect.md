# Security

If you discover a security vulnerability in this project, please report it privately
through GitHub's private vulnerability reporting on this repository. Do not file a
public issue, pull request, or discussion thread for suspected security problems.

## How to report

1. Go to the repository page on GitHub.
2. Click the Security tab.
3. Select "Report a vulnerability" and submit the form.

Include a clear description of the issue, steps to reproduce, the impact you
observed, and any proof of concept code or screenshots that help a maintainer
confirm the report.

## What to expect

- An initial acknowledgement within 7 days.
- A status update at least every 14 days until the report is resolved.
- Credit in the release notes if you ask for it and we ship a fix.

## Scope

This policy covers source code, configuration, and documentation in this
repository. It does not cover third party services linked from the project,
downstream forks, or user environments.
