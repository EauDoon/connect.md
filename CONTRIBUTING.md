# Contributing

The contributing guide for this repository is
[.github/CONTRIBUTING.md](.github/CONTRIBUTING.md), the copy GitHub links from
new issues and pull requests. It covers the product invariants a change must
preserve, the per-directory local checks CI runs (including the Linux-only API
lock file and what to do on Windows or macOS), and the pull request checklist.

For security reports, follow [SECURITY.md](SECURITY.md) instead of filing a
public issue.
